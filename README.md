# Deborah Akinsiku — Portfolio

Single-file premium portfolio site (adapted 1:1 from the varcopruden.com layout).

- **index.html** — the complete self-contained site (all images embedded as base64, no external dependencies). Open it directly in a browser, or serve the folder with any static server (e.g. `python3 -m http.server 8000`).
- **images/** — the original generated source images used in the build (hero, process slider, services, industries, writing, subscribe).

## Highlights
- Pixel-verified typography and responsive layout across 320–1920px
- Sticky scroll-scrubbed process section with image reel
- Hero slider, industries card slider, quote slider, insights, subscribe, footer
